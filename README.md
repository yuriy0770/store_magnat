# 🛒 Magnat Store - Магазин продуктов питания

Django-приложение для онлайн-продажи продуктов питания с системой пользователей и корзиной покупок.

## 🌟 Основные функции

- **📦 Каталог продуктов** с категориями: фрукты, овощи, молочные продукты, мясо, бакалея
- **👤 Система пользователей** с регистрацией, авторизацией и профилем
- **🛍️ Корзина покупок** с добавлением/удалением товаров
- **📱 Адаптивный дизайн** с Bootstrap
- **🔐 Безопасная аутентификация**

## 🛠 Технологии

- **Backend:** Django 5.2.7, Python 3.13
- **Database:** PostgreSQL
- **Frontend:** HTML, CSS, JavaScript, Bootstrap 5
- **Authentication:** Кастомная модель пользователя
- **Static files:** Django Static Files

## 🚀 Установка и запуск

### 1. Клонирование репозитория

git clone https://github.com/yuriy0770/store_magnat.git
cd store_magnat

👤 Модели данных
User - кастомная модель пользователя с доп. полями

Product - товары с категориями и изображениями

Cart - корзина покупок

Order - система заказов (в разработке)

🌐 Основные страницы
/ - главная страница

/products/ - каталог товаров

/users/login/ - вход

/users/register/ - регистрация

/users/profile/ - профиль пользователя

/cart/ - корзина покупок

🔧 Дополнительные возможности
Поиск товаров

Фильтрация по категориям

Валидация форм

Система сообщений
